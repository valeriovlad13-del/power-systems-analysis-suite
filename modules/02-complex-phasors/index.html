1. Complex arithmetic and polar conversion

Enter two complex quantities in rectangular form. The tool reports their sum, difference, product, quotient, and polar form. Division by zero is rejected.

Quantity A = a + jb

Quantity B = c + jd

Select Calculate to display results.

2. Impedance network reduction

Reduce two impedances connected in series or in parallel. Enter each impedance as R + jX in ohms. The parallel calculation uses complex arithmetic, not separate scalar R and X formulas.

Select Reduce network to display results.

Formulas and conventions

z = x + jy = |z|∠θ
|z| = √(x² + y²); θ = atan2(y, x)
(a + jb)(c + jd) = (ac − bd) + j(ad + bc)
Zseries = Z₁ + Z₂
Zparallel = (Z₁Z₂)/(Z₁ + Z₂)

Angles are reported in degrees, with atan2 preserving the correct quadrant. The impedance-network tool assumes both impedances use the same reference direction and units.

Worked example — supplementary

Given: Z = 12 + j36 Ω.

Find: magnitude and phase angle.

Formula: |Z| = √(R² + X²); θ = atan2(X,R).

Substitution: |Z| = √(12² + 36²) = √1440 = 37.947 Ω.

Angle: θ = atan2(36,12) = 71.565°.

Final answer: Z = 37.947∠71.565° Ω.

Interpretation: positive reactance gives a positive impedance angle under the usual R + jX convention.

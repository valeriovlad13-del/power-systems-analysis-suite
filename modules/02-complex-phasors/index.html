Start with the idea: why use complex numbers?

Alternating voltage and current change with time. In AC analysis, we often need to describe both a quantity's size and its phase angle. A complex number stores these together: the real part is plotted horizontally and the imaginary part vertically.

z = a + jb

a is the real part, b is the imaginary part, and j means the square root of −1. Electrical engineers use j rather than i because i commonly represents current.

Two forms, one quantity

Rectangular: z = a + jb
Polar: z = |z| ∠ θ

Rectangular form is convenient for adding and subtracting. Polar form is often convenient for describing magnitude and phase, and for multiplying or dividing complex quantities.

Quick check: For z = 3 + j4, what is the real part?
Reveal answer

The real part is 3. The imaginary part is 4, the coefficient of j.

Formulas and conventions

z = x + jy = |z|∠θ
|z| = √(x² + y²); θ = atan2(y, x)
(a + jb)(c + jd) = (ac − bd) + j(ad + bc)
Zseries = Z₁ + Z₂
Zparallel = Z₁Z₂Z₁ + Z₂

Angles are reported in degrees, with atan2 preserving the correct quadrant. The impedance-network tool assumes both impedances use the same reference direction and units.

Worked example: Complex operator expression (PSA 2, Problem 2)

Source: EE-32 Power Systems Analysis 2, first problem set, Problem 2, page 1; answer verified against the solution on page 2.

Problem statement: Evaluate a² + a + j in rectangular form, where a = 1∠120°.

Given: a = cos 120° + j sin 120°.

Find: a² + a + j = x + jy.

Step 1 — write a in rectangular form: a = −0.5 + j0.866025.

Step 2 — square a: a² = 1∠240° = −0.5 − j0.866025.

Step 3 — add a² and a: (−0.5 − j0.866025) + (−0.5 + j0.866025) = −1 + j0.

Step 4 — add j: (−1 + j0) + j = −1 + j.

Final answer: −1 + j.

Engineering interpretation: The imaginary parts of a and a² cancel because they have equal magnitudes and opposite signs. Keep the rectangular real and imaginary components separate when performing complex arithmetic.

Scope, assumptions & limitations

Complex quantities use rectangular form a + jb, with angles reported in degrees. Impedance reduction assumes both impedances use consistent units and refer to the same circuit conditions. Parallel reduction requires the sum of the impedances to be nonzero; division by zero is rejected.

This module teaches basic complex arithmetic and two-impedance series/parallel reduction. It does not perform a complete network solution or transient analysis.

Calculation steps

Base equations

Ibase = Sbase / (√3 × Vbase,LL)
Zbase = Vbase,LL² / Sbase
Ybase = 1 / Zbase

With Sbase in MVA and Vbase in kV, Ibase is in kA and Zbase is in Ω. These three-phase forms use total three-phase apparent power and line-to-line voltage.

Worked example — supplementary

Given Sbase = 100 MVA and Vbase = 138 kV:

  1. Find: Ibase, Zbase, and Ybase.
  2. Formula: use the three equations shown.
  3. Substitution: Ibase = 100/(√3 × 138); Zbase = 138²/100.
  4. Calculation: Ibase = 0.41837 kA; Zbase = 190.44 Ω; Ybase = 1/190.44.
  5. Final answer: 418.37 A, 190.44 Ω, and 0.005251 S (rounded).
  6. Engineering interpretation: these are the reference quantities used to express actual values in per-unit on this selected base.

Conversion steps

Conversion equations

Zpu = Zactual / Zbase
Zactual = Zpu × Zbase
Vpu = Vactual / Vbase
Ipu = Iactual / Ibase
Spu = Sactual / Sbase

When converting per-unit values back to physical units, multiply by the corresponding base. Ensure that current, voltage, and power use compatible system conventions.

Base-change derivation

Base-change equation

Zpu,new = Zpu,old × (Sbase,new / Sbase,old) × (Vbase,old / Vbase,new)²

The voltage ratio is squared. When the voltage bases are equal, this factor is 1.

If X/R is provided, the tool decomposes the impedance magnitude into R and X assuming a nonnegative inductive reactance. A magnitude and X/R ratio alone do not establish reactance sign.

Core concepts and common mistakes

Definition

Per-unit value = actual value / corresponding base value
  • Use the same base power throughout the network unless deliberately converting between bases.
  • Voltage bases on opposite sides of a transformer must follow the turns/voltage ratio.
  • Do not mix line-to-line and phase quantities in a single formula.
  • Impedance base is voltage squared divided by power base.
  • Per-unit impedance changes numerically with base choice; physical impedance does not.

Limitations

These calculators assume balanced system base quantities. They do not automatically infer transformer ratios or detect whether user-selected voltage bases correspond to the same transformer side.

Practice questions

  1. A three-phase system uses 50 MVA and 13.8 kV bases. Calculate Zbase.
  2. An impedance is 12 + j36 Ω on a 100 MVA, 138 kV base. Convert it to per-unit rectangular form.
  3. An equipment impedance is 8% on a 50 MVA base. Convert it to a 100 MVA base, keeping voltage base unchanged.
  4. Why must voltage bases follow transformer ratios in a multi-voltage network?
Reveal answer guide
  1. Zbase = 13.8²/50 = 3.8088 Ω.
  2. Zbase = 138²/100 = 190.44 Ω. Zpu = (12+j36)/190.44 ≈ 0.06301 + j0.18904 p.u.
  3. Old impedance = 0.08 p.u.; new = 0.08 × 100/50 = 0.16 p.u.
  4. Consistent voltage bases preserve the correct relationship of per-unit impedances across transformer-connected parts of the system.

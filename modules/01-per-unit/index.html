Base equations

Ibase = Sbase / (√3 × Vbase,LL)
Zbase = Vbase,LL² / Sbase
Ybase = 1 / Zbase

With Sbase in MVA and Vbase in kV, Ibase is in kA and Zbase is in Ω. These three-phase forms use total three-phase apparent power and line-to-line voltage.

Worked example — supplementary

Given: a balanced three-phase system with Sbase = 100 MVA and Vbase,LL = 138 kV.

  1. Find: the base current, base impedance, and base admittance.
  2. Equations: Ibase = Sbase/(√3 × Vbase,LL); Zbase = Vbase,LL²/Sbase; Ybase = 1/Zbase.
  3. Substitute: Ibase = 100/(√3 × 138) = 0.41837 kA; Zbase = 138²/100 = 190.44 Ω.
  4. Calculate admittance: Ybase = 1/190.44 = 0.005251 S.
  5. Final answers: Ibase = 0.41837 kA (418.37 A), Zbase = 190.44 Ω, and Ybase = 0.005251 S.
  6. Engineering meaning: these are reference values for expressing quantities in per-unit on the selected three-phase base.

Conversion equations

Zbase = Vbase,LL² / Sbase,3φ
Zpu = Zactual / Zbase; Zactual = Zpu × Zbase
Vpu = Vactual,LL / Vbase,LL
Ipu = Iactual,line / Ibase,line
Spu = Sactual,3φ / Sbase,3φ

The voltage and current bases are line-to-line voltage and line current for a balanced three-phase system. Apparent power is total three-phase apparent power. Keep these conventions consistent.

Worked example — supplementary

Given Z = 12 + j36 Ω on a 100 MVA, 138 kV three-phase base:

  1. Find Zbase = 138²/100 = 190.44 Ω.
  2. Normalize each component: Rpu = 12/190.44 = 0.06301; Xpu = 36/190.44 = 0.18904.
  3. Final answer: Zpu = 0.06301 + j0.18904 p.u. (rounded).
  4. Interpretation: both components are divided by the same positive real base impedance, so the impedance angle is unchanged.

Base-change equation

Zpu,new = Zpu,old × (Sbase,new / Sbase,old) × (Vbase,old / Vbase,new)²

The voltage ratio is squared. If both voltage bases are equal on the same transformer side, this factor is 1. Convert a percentage impedance to per-unit by dividing by 100 before changing bases.

Worked example — supplementary

An equipment impedance is 8% on a 50 MVA base. Convert it to a 100 MVA base with unchanged voltage base.

  1. Convert 8% to per-unit: Zpu,old = 8/100 = 0.08 p.u.
  2. Apply the equation: Zpu,new = 0.08 × (100/50) × (Vold/Vnew)².
  3. Because Vold = Vnew, Zpu,new = 0.08 × 2 × 1 = 0.16 p.u.
  4. Final answer: 0.16 p.u. = 16% on the new base.
  5. Interpretation: physical impedance is unchanged; its per-unit value changes with the selected base.
If X/R is provided, the tool decomposes the impedance magnitude into R and X assuming a nonnegative inductive reactance. A magnitude and X/R ratio alone do not establish reactance sign.

Core concepts and common mistakes

Definition

Per-unit value = actual value / corresponding base value
  • Use the same base power throughout the network unless deliberately converting between bases.
  • Voltage bases on opposite sides of a transformer must follow the turns/voltage ratio.
  • Do not mix line-to-line and phase quantities in a single formula.
  • Impedance base is voltage squared divided by power base.
  • Per-unit impedance changes numerically with base choice; physical impedance does not.

Limitations

These calculators assume balanced system base quantities. They do not automatically infer transformer ratios or detect whether user-selected voltage bases correspond to the same transformer side.

Theory & formulas

Per-unit value equals the actual quantity divided by its corresponding base. For a balanced three-phase system, use total three-phase MVA and line-to-line kV consistently.

Zbase = Vbase,LL² / Sbase,3φ; Ibase = Sbase,3φ/(√3 Vbase,LL)

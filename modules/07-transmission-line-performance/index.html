Core formula

Vs,phase ≈ Vr,phase + I(R + jX)

Worked example: Short-line voltage drop

Problem statement: A balanced three-phase load receives 50 MW at 132 kV and 0.90 lagging power factor. Total per-phase line impedance is 4 + j20 Ω. Estimate the line current and sending-end line voltage using the simplified short-line model.

Given: P = 50 MW, Vr,LL = 132 kV, PF = 0.90 lagging, R = 4 Ω/phase, X = 20 Ω/phase.

Find: I, approximate in-phase phase-voltage drop, and Vs,LL.

  1. Current: P√3 VLL PF = 50 × 106√3 × 132 × 103 × 0.90 ≈ 242.93 A.
  2. Power-factor angle: cos φ = 0.90, so sin φ = √(1 − 0.90²) ≈ 0.4359.
  3. In-phase phase drop: ΔV ≈ I(R cos φ + X sin φ) = 242.93[4(0.90) + 20(0.4359)] ≈ 2.993 kV.
  4. Quadrature component: ΔVq ≈ I(X cos φ − R sin φ) ≈ 3.950 kV.
  5. Use the simplified phasor estimate with Vr,phase = 132/√3 kV; Vs,LL ≈ √3 √[(132/√3 + 2.993)² + 3.950²] ≈ 137.35 kV.

Final answer: I ≈ 242.93 A; in-phase phase drop ≈ 2.993 kV; estimated sending-end line voltage ≈ 137.35 kV.

Interpretation: The estimated sending voltage is above the receiving voltage to account for the line's series impedance under the stated load. This is an approximate short-line calculation, not a full ABCD solution.

Assumptions and limitations

This is a short-line approximate voltage-drop tool, not the full ABCD model. Long-line and nominal-π/T models require complex phasor calculations.

Use the calculator output to follow each substitution. Results are estimates for the stated simplified model.

Theory & formulas

Short-line model used by this calculator

Vs,phase ≈ Vr,phase + I(R + jX)

For a lagging power factor, the approximate in-phase drop is ΔVphase ≈ I(R cos φ + X sin φ). The quadrature component is I(X cos φ − R sin φ), using the current reference defined by the receiving-end load.

This page does not calculate general ABCD constants, voltage regulation, or efficiency. Those require additional models and inputs.

Confirm the assumptions, sign convention, and units before applying a formula to a different system.

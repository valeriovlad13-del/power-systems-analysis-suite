Core formula

Vs,phase ≈ Vr,phase + I(R + jX)

Worked example: Short-line voltage regulation

Problem statement: An 11 kV, three-phase short transmission line has per-phase resistance 1.5 Ω and reactance 4 Ω. It supplies a 5,000 kVA load at 0.8 lagging power factor at the receiving end. Estimate the percentage voltage regulation using the short-line phasor model.

Given: Vr,LL = 11 kV; S = 5,000 kVA; PF = 0.8 lagging; R = 1.5 Ω/phase; X = 4 Ω/phase.

Find: sending-end voltage and percentage voltage regulation.

  1. Current magnitude: I = S√3 VLL = 5,000 × 10³√3 × 11 × 10³ ≈ 262.43 A.
  2. Power-factor angle: φ = cos⁻¹(0.8) = 36.87°. For a lagging load, I = 262.43∠−36.87° A.
  3. Receiving-end phase voltage: Vr,ph = 11,000√3 ≈ 6,350.85 V.
  4. Series impedance: Z = 1.5 + j4 Ω. Voltage drop: IZ = (262.43∠−36.87°)(1.5 + j4) ≈ 944.8 + j603.6 V.
  5. Sending-end phase voltage: Vs,ph = Vr,ph + IZ ≈ 7,295.6 + j603.6 V, so |Vs,ph| ≈ 7,320.5 V. Thus Vs,LL ≈ √3(7,320.5) = 12.68 kV.
  6. Voltage regulation: %VR = |Vs| − |Vr||Vr| × 100% = 12.68 − 1111 × 100% ≈ 15.26%.

Final answer: sending-end line voltage ≈ 12.68 kV; voltage regulation ≈ 15.26%.

Engineering interpretation: The series impedance causes the sending-end voltage magnitude to exceed the receiving-end voltage for this lagging load. This uses the short-line model and ignores shunt capacitance.

Theory & formulas

Short-line model used by this calculator

Vs,phase ≈ Vr,phase + I(R + jX)

For a lagging power factor, the approximate in-phase drop is ΔVphase ≈ I(R cos φ + X sin φ). The quadrature component is I(X cos φ − R sin φ), using the current reference defined by the receiving-end load.

This page does not calculate general ABCD constants, voltage regulation, or efficiency. Those require additional models and inputs.

Confirm the assumptions, sign convention, and units before applying a formula to a different system.

Additional worked problem: Transmission efficiency

Problem: A 69 kV three-phase short line is 16 km long and has per-phase series impedance 0.125 + j0.4375 Ω/km. It delivers 70 MVA at 0.80 lagging power factor at 64 kV receiving voltage. Determine transmission efficiency using the short-line model.

Given / find: Sr = 70 MVA, PF = 0.80 lagging, Vr,LL = 64 kV, length = 16 km, z = 0.125 + j0.4375 Ω/km; find η.

  1. Receiving current: I = 70 × 10⁶√3 × 64 × 10³ = 631.48 A, with φ = cos⁻¹(0.8) = 36.87° lagging.
  2. Total series impedance: Z = (0.125 + j0.4375)(16) = 2 + j7 Ω.
  3. Receiving phase voltage: Vr,ph = 64,000/√3 = 36,950.4 V.
  4. Sending phase voltage: Vs,ph = Vr,ph + IZ. Using I = 631.48∠−36.87° A gives |Vs,ph| ≈ 40.708 kV.
  5. Sending real power from the per-phase complex-power calculation is approximately 58.393 MW. Receiving real power is Pr = 70(0.80) = 56 MW.
  6. Efficiency: η = PrPs × 100% = 5658.393 × 100% ≈ 95.90%.

Answer: η ≈ 95.90%, consistent with the additional's worked answer. This estimate assumes the short-line series model and neglects shunt charging current.

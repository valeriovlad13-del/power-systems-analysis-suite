Start with the idea: splitting an unbalanced set

When three phase voltages or currents are unbalanced, symmetrical components let us represent them as three simpler sets: positive sequence, negative sequence, and zero sequence. Each set has a defined phase relationship. Adding the three sets reconstructs the original phase quantities.

  • Positive sequence: equal magnitudes with the normal phase order A–B–C.
  • Negative sequence: equal magnitudes with the reverse phase order A–C–B.
  • Zero sequence: all three phasors have the same angle.

These are mathematical components, not three separate physical generators. They are useful in unbalanced-condition and fault calculations.

V₀ = Va + Vb + Vc3
V₁ = Va + aVb + a²Vc3; V₂ = Va + a²Vb + aVc3

Here a = 1∠120°. The formulas use complex phasors, not just their magnitudes.

Quick check: In a zero-sequence set, what is the angle relationship between Va₀, Vb₀, and Vc₀?
Reveal answer

They are aligned and have the same phase angle. Their magnitudes are equal in an ideal zero-sequence set.

Worked example: Balanced positive-sequence set

Problem statement: Generate an ideal balanced positive-sequence voltage set with phase-A voltage 120∠0° V.

Given: Va = 120∠0° V and positive sequence.

Find: Vb and Vc, and state the sequence components for this ideal balanced set.

  1. For positive sequence, phase B lags phase A by 120°: Vb = 120∠−120° V.
  2. Phase C leads phase A by 120°: Vc = 120∠+120° V.
  3. For an ideal balanced positive-sequence set, the positive-sequence component is 120 V and the negative- and zero-sequence components are zero.

Final answer: Va = 120∠0° V, Vb = 120∠−120° V, Vc = 120∠+120° V; V1 = 120 V, V2 = 0, V0 = 0.

Interpretation: This is a generated ideal balanced set, not a decomposition of measured unbalanced phasors.

Scope, assumptions & limitations

This quick tool generates an ideal balanced set only; general unbalanced sequence decomposition requires complex phasor inputs for all three phases.

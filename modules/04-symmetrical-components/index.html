Core formula

a = 1∠120°; V0 = (Va + Vb + Vc)/3; V1 = (Va + aVb + a²Vc)/3; V2 = (Va + a²Vb + aVc)/3

Worked example

For a 120 V positive-sequence set with Va = 0°, Vb = −120°, and Vc = +120°; the ideal balanced set has V1 = 120 V and V0 = V2 = 0.

Assumptions and limitations

This quick tool generates an ideal balanced set only; general unbalanced sequence decomposition requires complex phasor inputs for all three phases.

Transmission Line Parameters

Estimate inductance and inductive reactance per unit length for a simplified transposed line.

← Back to all modules
How to use this module: Start with the conductor-spacing diagram. Then use the geometric mean distance (GMD) and geometric mean radius (GMR) to estimate inductance and reactance per unit length for a simplified overhead line.

Learning outcomes

  • Explain how conductor geometry affects line inductance.
  • Calculate geometric mean distance for a transposed three-phase line.
  • Estimate inductance and inductive reactance per unit length using consistent units.

Start with the idea: why does conductor spacing matter?

Power-line conductors create magnetic and electric fields around them. The conductor geometry affects the line's inductance and capacitance, which in turn affect voltage drop, reactive power, and line performance.

For a simplified transposed three-phase overhead line, GMD summarizes the spacing between phases, while GMR represents the conductor's effective radius for inductance calculations. GMR is not always the same as the physical outside radius.

GMD = ∛(Dab × Dbc × Dca)

For a transposed line, this equivalent spacing helps represent the three phase relationships with one average value.

Inductance and reactance

L = 2 × 10⁻⁷ ln(GMDGMR) H/m
X = 2πfL Ω/m

The natural logarithm ln uses the ratio GMD/GMR, so the numerator and denominator must use the same length unit. The ratio must be greater than 1 for this simplified model to produce positive inductance.

Quick check: If phase spacing increases while GMR stays the same, what happens to the calculated inductance?
Reveal answer

It increases because ln(GMDGMR) increases as GMD increases.

Worked example: Single-phase two-wire loop inductance (PSA 1, Problem 2)

Source: EE-29 Power Systems Analysis 1, first problem set, Problem 2, page 1; the worked result is shown in the supplied solution on page 4.

Problem statement: A single-phase line uses two parallel conductors separated by 2 m. Each conductor has a diameter of 1.2 cm. Calculate the loop inductance per kilometre.

Given: D = 2 m; conductor diameter d = 0.012 m; conductor radius r = 0.006 m.

Find: total loop inductance per kilometre.

  1. For a solid round conductor, GMR = 0.7788r = 0.7788(0.006) = 0.004673 m.
  2. For the two-wire loop, Lloop = 0.4 ln(D/GMR) mH/km.
  3. Substitute: Lloop = 0.4 ln(2/0.004673) = 0.4 ln(427.99).
  4. Evaluate: Lloop ≈ 0.4(6.059) = 2.424 mH/km.

Final answer: Lloop ≈ 2.42 mH/km, consistent with the reviewer's rounded result of about 2.423 mH/km.

Engineering interpretation: This is the total loop inductance for the two-conductor single-phase circuit, not the inductance of one conductor alone. Keep the geometry ratio dimensionless inside the logarithm.

Scope, assumptions & limitations

Assumes a transposed symmetrical overhead line and a single conductor per phase. Bundling, earth return, and other corrections are not included.

Practice problems: Geometric mean distance and inductance

  1. A transposed three-phase line has D_ab = 3 m, D_bc = 4 m, and D_ca = 5 m. Calculate GMD.
  2. For GMD = 4 m and GMR = 0.01 m, estimate inductance in mH/km.
  3. Why must GMD and GMR use the same unit?
Reveal answer guide
  1. GMD = (3 × 4 × 5)^(1/3) ≈ 3.915 m.
  2. L = 2 × 10⁻⁷ ln(400) H/m ≈ 1.198 mH/km.
  3. The logarithm’s argument is a ratio and must be dimensionless.

Reviewer problem: Inductance of an equilateral three-phase line (PSA 1, Problem 5)

Source: EE-29 Power Systems Analysis 1, first problem set, Problem 5, page 1; solution on page 4.

Problem: A transposed three-phase line has equilateral conductor spacing of 8 m and conductor diameter of 5 cm. Calculate inductance per phase per kilometre.

Given: Dm = 8 m; d = 0.05 m; r = 0.025 m.

Find: L per phase in mH/km.

  1. For a solid round conductor, GMR = 0.7788r = 0.7788(0.025) = 0.01947 m.
  2. For a transposed three-phase line, L = 0.2 ln(Dm/GMR) mH/km.
  3. L = 0.2 ln(8/0.01947) = 0.2 ln(410.88) ≈ 1.204 mH/km.

Answer: L ≈ 1.204 mH/km per phase. The GMR is based on conductor radius, not diameter.

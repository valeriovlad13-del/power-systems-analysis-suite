Core formula

yij = 1R + jX = R − jXR² + X²

Worked example: Branch admittance and per-unit conversion

Problem statement: A series branch has impedance Z = 0.1 + j0.4 Ω. Calculate its admittance in siemens and convert it to per-unit on a 100 MVA, 13.8 kV line-to-line base.

Given: R = 0.1 Ω, X = 0.4 Ω, Sbase = 100 MVA, Vbase,LL = 13.8 kV.

Find: y = G + jB and ypu.

Formula: y = 1/(R + jX) = (R − jX)/(R² + X²); Zbase = Vbase,LL²/Sbase; ypu = yZbase.

Substitution: R = 0.1 Ω, X = 0.4 Ω, Sbase = 100 MVA, and Vbase,LL = 13.8 kV.

Step-by-step calculation:

Formula: y = 1/(R + jX) = (R − jX)/(R² + X²); Zbase = Vbase,LL²/Sbase; ypu = yZbase.

Substitution: R = 0.1 Ω, X = 0.4 Ω, Sbase = 100 MVA, and Vbase,LL = 13.8 kV.

Step-by-step calculation:

  1. Denominator: R² + X² = 0.1² + 0.4² = 0.17 Ω².
  2. Admittance: y = R − jXR² + X² = 0.1 − j0.40.17 = 0.588235 − j2.352941 S.
  3. Base impedance: Zbase = Vbase,LL²Sbase = 13.8²100 = 1.9044 Ω.
  4. Per-unit admittance: ypu = y Zbase = (0.588235 − j2.352941)(1.9044) ≈ 1.120235 − j4.480941 p.u.

Final answer: y ≈ 0.588235 − j2.352941 S; ypu ≈ 1.120235 − j4.480941 p.u.

Interpretation: This is the admittance of one branch. A complete Ybus matrix also needs the network's bus connections and all branch/shunt models.

Theory & formulas

Bus admittance and load-flow iteration

Ybus diagonal terms sum incident admittances; off-diagonal terms are the negative of direct branch admittance, absent special models.

Confirm the assumptions, sign convention, and units before applying a formula to a different system.

Practice problem: Branch admittance and per-unit conversion

A branch has impedance Z = 0.1 + j0.4 Ω. Calculate its admittance in rectangular form, then calculate its per-unit admittance on a 100 MVA, 13.8 kV three-phase base.

Check your result

R² + X² = 0.17 Ω²; y = 0.588235 − j2.352941 S. Zbase = 13.8²/100 = 1.9044 Ω. Therefore ypu = y × Zbase ≈ 1.120235 − j4.480941 p.u.

Scope, assumptions & limitations

This tool calculates one series-branch admittance. A complete Ybus matrix also requires network topology and branch connections; load flow additionally requires bus specifications and a numerical solution method.

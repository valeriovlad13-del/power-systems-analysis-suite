Core formula

C(P) = a + bP + cP²; incremental cost dC/dP = b + 2cP

Worked example

For C(P) = 100 + 8P + 0.02P² at 50 MW, C = 550 currency/h and incremental cost = 10 currency/MWh.

Assumptions and limitations

A single-unit cost evaluation is not an economic dispatch solution. Dispatch requires demand balance, unit limits, incremental-cost equalization, and loss treatment if applicable.

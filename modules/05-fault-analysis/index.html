Core formula

I3φ = Vphase / |Zth + Zf|; Ssc = √3 VLL Iline

Worked example

With 13.8 kV and a total impedance magnitude of 1.5 Ω, the simplified current estimate is 13,800/(√3×1.5) ≈ 5.31 kA.

Assumptions and limitations

This is a simplified magnitude-only balanced-fault estimate. Full fault studies use complex sequence impedances, prefault voltage, grounding, and fault type.
